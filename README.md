
# Business Report Generator

A Python application that analyzes sales data from Excel files and generates structured business reports.

## Features

- Read sales data from Excel workbooks.
- Allow users to select a worksheet.
- Validate input data and detect errors.
- Detect and exclude exact duplicate rows.
- Analyze sales by product.
- Generate a new Excel report.

## Project Status

Currently under development.

- Python
